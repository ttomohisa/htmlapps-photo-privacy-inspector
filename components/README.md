# Reusable UI components

These files are source snippets for apps created from this template. They are **not automatically bundled** by the builder. Copy or adapt the component inside `src/index.template.html` so the final release remains one self-contained HTML file.

- [`confirm-dialog.html`](confirm-dialog.html) — Promise-based confirmation dialog. Centered on desktop, bottom-sheet style on smartphones, safe-area aware, keyboard accessible, and suitable for destructive actions.
